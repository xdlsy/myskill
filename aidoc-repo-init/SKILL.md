# 根目录 AGENTS.md 生成

## 概览

基于 `.aidoc/phase0/repo-profile.md` 中已确认的代码仓画像，生成根目录 `AGENTS.md`（80-150 行）。

## 前置条件

- `.aidoc/phase0/repo-profile.md` 必须存在且内容完整（由 `aidoc-repo-explore` 生成）
- 模板位于 `templates/root-agents.tmpl.md`

## 数据到章节的映射

| 章节 | 数据来源 | 何时生成 |
|---------|--------|------|
| **项目概览** | README.md（如果存在）+ 画像数据中的模块探索结果 | 始终 |
| **构建与测试命令** | 画像数据中检测的构建系统与测试框架 | 始终 |
| **代码风格** | 画像数据中检测的 lint/formatter 配置 | 仅当检测到 lint 配置时 |
| **测试指南** | 画像数据中检测的测试框架 + 直接读取测试目录 | 始终 |
| **提交与 PR 规范** | 画像数据中检测的提交规范 + CI 流水线 | 仅当检测到规范时 |
| **注意事项 / 坑点** | — | 始终（带 `<!-- HUMAN_REVIEW -->` 占位符） |
| **仓库结构** | 画像数据中的目录树 + 模块依赖关系 | 始终 |

## 注意事项 / 坑点

从模块类型自动检测明显的约束条件：
- "`internal/` 模块不得被外部包导入"（Go）
- "`domain/` 包不得依赖 `adapter/` 包"（Java）
- "`core/` 不得导入 `apps/` 模块"（monorepo）

其余内容标记为 `<!-- HUMAN_REVIEW: ... -->`。

## 每个章节的置信度标注

- `[✓ 自动]` — 纯粹来自画像自动采集数据（如构建命令）
- `[~ 推断]` — AI 解读（如模块描述）
- `[? 待审核]` — 占位符，需要人工补充（如坑点）

## 生成后

1. 展示完整的 AGENTS.md 供审阅。接受内联修改。
2. 用户确认后，将完成报告写入 `.aidoc/phase1/report.md`：

```markdown
# 阶段 1 完成报告

## 生成结果
- 根 AGENTS.md：{行数} 行
- 生成时间：{时间戳}

## 章节覆盖
| 章节 | 置信度 | 状态 |
|------|--------|------|
| 项目概览 | [~ 推断] | ✓ |
| 仓库结构 | [✓ 自动] | ✓ |
| 构建与测试命令 | [✓ 自动] | ✓ |
| 代码风格 | [~ 推断] | ✓ / 已跳过（无 lint 配置） |
| 测试指南 | [✓ 自动] | ✓ |
| 提交与 PR 规范 | [~ 推断] | ✓ / 已跳过（无规范） |
| 禁止事项 / 常见陷阱 | [? 待审核] | ✓（含 HUMAN_REVIEW 占位符） |

## 待人工补充
- {列出所有 HUMAN_REVIEW 标记的位置}
```

> CLAUDE.md 不在此处生成 — 它属于 `claude-sync` skill，在所有 AGENTS.md 文件定稿后运行。

## 幂等性

如果目标路径已存在文件：
- 不要静默覆盖
- 展示现有文件与生成内容的差异
- 让用户选择：保留现有、合并或替换
