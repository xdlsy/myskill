# 架构决策记录（ADR）

本目录记录本项目的架构决策。遵循 [MADR 2.1.2](https://adr.github.io/madr/) 格式。

## 什么是 ADR？

架构决策记录（Architecture Decision Record）是一份简短文本文件，描述一项具体的架构决策，包括背景、考虑的方案、最终选择和理由。

## 何时写 ADR？

- 选择技术框架/数据库/库时
- 设计 API 协议或通信模式时
- 制定编码约定或架构约束时
- 任何代价高昂、难以逆转的决策
